**Actividad Semana 06 — Clasificación de marketing bancario**

En este trabajo se utilizan dos modelos de clasificación para predecir si un cliente contratará un depósito a plazo: Regresión Logística y Árbol de Decisión.

Se comparan sus resultados mediante métricas de evaluación como exactitud, precisión, recall y F1-score.

**Archivos:**

* `clasificacion_marketing_bancario.ipynb`: notebook con la exploración de datos, preparación, entrenamiento, evaluación y comparación de los modelos.
* `dataset/bank.csv`: conjunto de datos utilizado para el análisis.
